## Architecture Decisions

### FR-001: Page load validation
**Approach:** Use Playwright `page.goto()` with file:// protocol
**Path:** `file:///C:/EA Work/Spec-kit/Rollout-dashboard-using-speckit/Package/Rollout/rllot_dashboard.html`
**Check:** page.title() or page.locator("body").is_visible()
**Why:** Direct file access — no server needed for static HTML

### FR-002: Title validation
**Approach:** page.locator("h1") or page.title() contains check
**Expected:** "GHCP Rollout Dashboard"
**Why:** Simple text assertion — most reliable for static HTML

### FR-003: Section presence validation
**Approach:** page.locator() for each section heading or table
**Sections to check:**
- BackEnd_Unit_Testing
- Gen_Test_Case
- Gen_Scripts_4_PostMan
**Why:** Three separate assertions — one per section — clear failure messages

### FR-004: Data accuracy validation
**Approach:** Read JSON first → parse HTML as string → compare
**Implementation:**
```python
# Read source
with open("Package/Rollout/rllot_data.json") as f:
    data = json.load(f)

# Get first team name from JSON
first_team = data["BackEnd_Unit_Testing"][0]["Team"]

# Verify it appears in HTML
assert page.locator(f"text={first_team}").is_visible()
```
**Critical rule:** No hardcoded expected values — always read from JSON
**Why:** If JSON changes tomorrow, test still works correctly

### FR-005: CSP meta tag validation
**Approach:** Read HTML file as raw string → search for CSP pattern
**Implementation:**
```python
with open("Package/Rollout/rllot_dashboard.html") as f:
    html = f.read()
assert "content-security-policy" in html.lower()
```
**Why:** File-based check — faster than Playwright DOM — catches CSP in meta tag

### FR-006: No inline handlers validation
**Approach:** Read HTML as string → regex search for on*= patterns
**Implementation:**
```python
import re
with open("Package/Rollout/rllot_dashboard.html") as f:
    html = f.read()
inline_handlers = re.findall(r'\bon\w+\s*=', html)
assert len(inline_handlers) == 0
```
**Why:** Direct HTML parse — not screenshot — catches all inline handler patterns

### FR-007: Baseline screenshot
**Approach:** Playwright full page screenshot after all tests pass
**Path:** tests/screenshots/rollout/baseline.png
**Timing:** Always last test in file
**Why:** Known-good visual reference after successful validation run
