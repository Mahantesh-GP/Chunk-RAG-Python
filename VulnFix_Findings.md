## Finding 1 — Compile Time Error

**Type:** Compile Time Error  
**Severity:** HIGH  
**File:** `VulnDemo.Api/Program.cs` (lines 36–40)  
**Errors:** 13 errors (CS1010, CS1002, CS1525, CS1012)

### What Happened
The tool applied fix for **F-006 (Plaintext DB seed password)** by modifying the SQL inside a C# verbatim string. It inserted SQL-style comments (`--`) **outside** the string literal and used single quotes (`'admin'`) which C# interpreted as character literals.

### Wrong Code Generated by Tool
```csharp
-- F-003 FIXED: Plaintext password removed   ← SQL comment outside C# string (WRONG)
-- TODO: Seed a bcrypt/PBKDF2 hash here      ← causes CS1010 error

INSERT OR IGNORE INTO Users (Id, Username, Password) 
VALUES (1, 'admin', 'CHANGE-ME-USE-BCRYPT-HASH');  ← single quotes cause CS1012
```

### Correct Way Should Be
```csharp
// F-003 FIXED: Plaintext password removed   ← C# comment (CORRECT)
// TODO: Seed a bcrypt/PBKDF2 hash here

cmd.CommandText += @"
    INSERT OR IGNORE INTO Users (Id, Username, Password) 
    VALUES (1, 'admin', 'CHANGE-ME-USE-BCRYPT-HASH');
";
```

### Root Cause
Tool mixed **SQL comment syntax** (`--`) with **C# code context**. Comments outside a string literal must use C# format (`//`), not SQL format (`--`).

### Impact
Build fails completely. App cannot run.

## Finding 2 — Runtime Error

**Type:** Runtime Error  
**Severity:** MEDIUM  
**Endpoint:** `POST /api/Todo`  
**Error:** 500 Internal Server Error

### What Happened
The tool applied fix for **F-005 (Missing Authentication)** by adding:
- `builder.Services.AddAuthentication()` — stub only
- `builder.Services.AddAuthorization()`
- `[Authorize]` attribute on `TodoController`

However the authentication scheme (JWT Bearer) was **not fully configured**. When any request hits `[Authorize]`, ASP.NET Core looks for a `DefaultChallengeScheme` which does not exist — causing a runtime crash.

### Error in Terminal
```
System.InvalidOperationException: No authenticationScheme was specified,
and there was no DefaultChallengeScheme found.
```

### Correct Way Should Be
```csharp
// Either complete JWT setup:
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(opts => { opts.TokenValidationParameters = new TokenValidationParameters { ... }; });

// OR do not add [Authorize] until JWT is fully configured
```

### Root Cause
Tool applied a **partial fix** — added `[Authorize]` without completing the full JWT authentication stack. The stub `AddAuthentication()` with no scheme registered causes crash at runtime.

### Impact
All CRUD operations (POST, GET with auth) return 500. App runs but core features broken.
